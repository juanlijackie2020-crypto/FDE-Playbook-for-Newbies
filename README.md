# FDE 学习与交付手册

离线优先的腾讯云 ADP FDE 个人备考应用。Windows 电脑优先，手机辅助。考试日期：2026 年 10 月 23 日。

## Windows 开始使用

1. 安装 Node.js LTS（建议 22 或 24）。应用无第三方运行依赖，无需运行 npm install。
2. 解压应用，双击 `start-windows.cmd`，保持终端窗口开启。
3. 在 Edge 或 Chrome 地址栏输入 `http://127.0.0.1:4173`。
4. 等待左下角显示“离线应用已就绪”。初次打开必须由本地服务器提供，不能直接双击 index.html。
5. 可以使用浏览器的安装应用功能；若浏览器不显示安装入口，继续在浏览器使用即可。离线核心缓存成功后，可断网阅读、练题；第一次访问和缓存失效后需要重新启动本地服务器。

命令行启动：在应用目录执行 `npm start`。保持同一浏览器、同一地址和端口；更换地址会形成独立存储空间。浏览器数据可能被清理，定期备份。

## 已实现

- 学习首页、考试倒计时、每日 25 / 20 / 15 分钟任务勾选与能力分类。
- PDF、TXT、Markdown 与浏览器支持的视频本地导入，SHA-256 去重，资料信息编辑、阅读标记与笔记。
- 文本与标题搜索；PDF 使用浏览器原生阅读器。尚未实现 PDF 正文提取、OCR、视频转写、Markdown 富文本渲染或自动课程抓取。
- 题库 JSON 导入、单选和多选、答案解析、来源定位、主题筛选、复盘笔记与历史错题。
- 60 题 / 90 分钟模拟、题目标记、自动保存、刷新恢复、到时交卷、分数与逐题复盘。
- 13 个字段的案例编辑、类型标签和 Markdown 导出。
- 包含资料原件的完整 JSON 备份与恢复，以及离线核心缓存检查。

当前没有官方课程内容或考试题库。2 道可手动加载的题目仅为功能示例，不代表腾讯考试知识，不能用于完整模拟。题型配比 40 单选 / 20 多选为分值推导，待官方确认；多选按全部选对得分。

## 导入资料与题目

在“资料书架”导入 PDF / TXT / MD / MP4 / WebM / OGG。浏览器不支持的视频编码需要先用合法方式转换；不保证所有视频都能播放。大视频与备份会占用内存，建议分批导入。

先在资料“信息”中记录真实来源、版本、使用范围，并复制资料 ID。在“数据与离线”下载题库模板。填写 `sourceId`、`locator`、题干、选项、答案、总解析及每个选项解析，随后导入。

`origin` 区分 official（官方提供，由导入者核验）、generated（资料生成）、demo（功能示例）；`status` 区分 draft、pending、reviewed。只有人工核对后标为 reviewed 的题才能练习，只有非示例已审校题可用于模拟。来源标签不能证明真实性。

题目示例见模板下载功能。答案索引从 0 开始。资料缺失、选项解析不完整或 ID 重复时拒绝导入，不进行部分导入。资料被题目引用后不能删除，确保依据仍可回看。

## 私有数据与分享

分享应用代码与空应用包即可；不要分享你的资料备份。资料、题库、案例、笔记保存在当前浏览器，应用不上传数据，不会自动把电脑数据同步到手机。

“数据与离线”可导出包含所有资料的私有备份；恢复会替换当前记录。先备份，再恢复。备份检查资料 SHA-256，损坏的文件拒绝恢复。手机可在 HTTPS 托管的空应用中导入同一备份；当前未部署公开站点，也未验证实体手机安装。

运行时服务器仅提供应用核心文件，不暴露 README、测试结果或其他目录。仍不应把私有资料提交到 Git 或静态站点。

## 验证与开发

`npm test` 运行 Node 内置逻辑测试。浏览器集成测试另需 Playwright 与 Chromium，当前云环境已提供，执行 `npm start` 后运行 `npm run test:browser`；其他环境需自行准备这两个测试工具。可用 `CHROMIUM_PATH` 指定 Chromium 可执行文件。

浏览器测试覆盖导入、阅读、笔记、单选多选、错题、案例、模拟与刷新恢复、完整备份到新存储恢复、断网重开和移动宽度。生成的测试题只在隔离浏览器中存在，不打包到应用。

测试截图在忽略目录 `test-results/`。目前验证平台为 Linux Chromium；Windows 脚本和实体手机尚未实际运行。

## 界面无法下载 ZIP 时

打开 `FDE-standalone.html`，选择 Copy file content，将完整内容粘贴到 Windows 记事本。另存为 `FDE.html`，文件类型选择“所有文件”，编码 UTF-8；用 Edge / Chrome 打开。单文件版嵌入全部脚本与样式，无需 Node 或本地服务器。请保持文件路径不变，移动前导出备份。

内嵌版计分、资料阅读与保存笔记已通过浏览器验证；云浏览器管理策略禁止 file:// 导航，因此未验证直接打开本地文件的行为，Windows 实机仍待验证。若浏览器限制本地存储或脚本，请使用 README 上述本地服务器方式。
